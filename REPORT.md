Создан в том же стиле, что и существующий plist моста: запускает
`tailscale funnel 8443` с `RunAtLoad` + `KeepAlive`, чтобы публичный
HTTPS-туннель (от которого зависят вебхуки Telegram) поднимался автоматически
и перезапускался при сбоях; логи пишутся в `/tmp/`.

### `e588134` — примечание в README

Plist предполагает путь `/usr/local/bin/tailscale` (Homebrew/standalone). Для
установки из Mac App Store путь другой
(`/Applications/Tailscale.app/Contents/MacOS/Tailscale`), его нужно поправить
в `ProgramArguments`. Проверка — `which tailscale`.
